# IStudio Data Analytics Internship Project

This project was completed as part of my IStudio Data Analytics Internship. It demonstrates an end-to-end data analytics workflow involving data extraction, cleaning, transformation, reconciliation, and visualization.

## Key Activities

* Extracted active user data using SQL and window functions.
* Cleaned and processed server log transaction data using Python and Pandas.
* Used Regular Expressions (Regex) to extract transaction details.
* Handled missing exchange-rate values.
* Merged user, transaction, and exchange-rate datasets.
* Calculated USD revenue from EUR transaction values.
* Analyzed monthly revenue and top customers.
* Created visualizations using Matplotlib.

## Technologies Used

Python | Pandas | SQL | SQLite | Regex | Matplotlib | Jupyter Notebook

## Project Outcome

Gained practical experience in data cleaning, data integration, financial data reconciliation, data analysis, and data visualization.
